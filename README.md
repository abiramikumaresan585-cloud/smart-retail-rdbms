# Smart Retail RDBMS

## Project Description
Smart Retail RDBMS is a database management system project developed using Oracle SQL and PL/SQL.

This project covers database design, relational models, normalization, SQL queries, joins, PL/SQL programming, cursors, exceptions, procedures, functions, packages and triggers.

## Technologies Used
- Oracle Database 21c Express Edition
- SQL
- PL/SQL
- SQL*Plus
- GitHub

## Project Structure
The project contains 15 weekly folders covering database concepts and practical implementations.

## How to Run the SQL Scripts

1. Install Oracle Database.
2. Open SQL*Plus.
3. Connect to your database.
4. Navigate to the required SQL script folder.
5. Execute the required script using:

```sql
@create_tables.sql
```
